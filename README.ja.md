# VR FWI Studio
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

VR FWI Studioはウェブベースの仮想現実 (VR) アプリケーションで、ユーザーが360度の画像を表示できます。

## デモ
デモは https://code4fukui.github.io/vr-fwistudio/ で利用可能です。

## 機能
- VR環境で360度画像を表示
- 背景画像の回転をサポート

## 使い方
アプリケーションを実行するには、WebVRをサポートしているウェブブラウザで `index.html` ファイルを開くだけです。
